One funny pickup line a robot could use, written by a deterministic, stdlib-only Python program. The line:

> I don't have a heart, just a processor, but it overclocks every time you smile.

The joke grows out of being a machine: a processor that overclocks is a robot's version of a heart racing.

## How to run

```sh
python3 main.py
```

This writes the pickup line (a single line, under 200 characters) to `/output/entry.txt`.
